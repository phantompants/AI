# Alt text guide

Alt text is a short written description of an image. It is read aloud by screen readers, shown when an image fails to load, and used by search engines.

## Rules

1. Say what the image shows and why it is there. Do not start with "image of" or "photo of".
2. Keep it to one sentence, about 125 characters at most.
3. Use plain words. Include visible text that matters (a sign, a sponsor name).
4. Describe only what can be seen or what the user told you. Do not guess names, places, dates or numbers.
5. Name people only if the user supplied the names and agrees to them being published.
6. Do not stuff keywords.

## By type

| Type | What to write | Example |
|---|---|---|
| Hero photo | The main subject and setting | Green Jeep with dinosaur decals parked on a red dirt track at sunrise |
| Gallery photo | What is happening | Two team members fitting a roof rack to the Jeep |
| Logo | The organisation's name, and "logo" only if needed for sense | Acme Auto Parts |
| Sponsor logo in a linked list | The sponsor's name | Acme Auto Parts |
| Decorative image or divider | Empty alt (`alt=""`) so screen readers skip it | (empty) |
| Chart or screenshot | What it shows and the key point | Bar chart: donations rose from March to June |

## Weak and better

| Weak | Better |
|---|---|
| IMG_4021 | Team Jeep in front of the workshop with its bonnet decal visible |
| Car photo | Dark green 4WD with a large dinosaur skeleton decal on the door |
| Photo of people smiling | Four team members standing beside the Jeep holding a Variety banner |

## Check

- Does the sentence still make sense if the image is missing?
- Does it add anything the nearby text does not already say? If not, consider empty alt.
