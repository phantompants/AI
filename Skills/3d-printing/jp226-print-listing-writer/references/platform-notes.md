# Platform notes

Platforms change their rules. Treat these as a starting point and confirm in the seller tools before publishing.

## eBay Australia

| Item | Note |
|---|---|
| Title | Up to 80 characters. Use as many as make sense. Avoid capitals, symbols and emoji. |
| Item specifics | Fill in as many as apply. They drive search filters. |
| Condition | New, for a new print. |
| Photos | Real photos on a plain background, plus one for scale. |
| Description | Keep it clear on mobile. Short paragraphs and a list for key facts. |
| Postage | State dispatch time and the service. Make the cost clear. |
| Brand | "Unbranded" or the seller's own name. Do not name another brand. |

## Etsy

| Item | Note |
|---|---|
| Title | Up to 140 characters. Put the main keyword first. |
| Tags | Up to 13, each up to 20 characters. Use all 13, each different. |
| Attributes | Colour, material, occasion and so on. Fill in what applies. |
| Photos | First photo matters most. Show scale, detail and colour options. Add alt text. |
| Made by | Etsy asks who made the item and how. Answer truthfully. |
| Variations | Use for colours and sizes, with clear names. |
| Processing time | Set an honest figure, including print time. |

## Both

- Say the item is 3D printed and may show fine layer lines. It sets expectations and reduces returns.
- Screens differ, so colours may vary slightly. Filament colours also vary between batches.
- If the model is licensed from another designer, check the licence allows commercial use before listing.
- A 3D printed item is not food safe, toy tested or certified unless proven. Leave the claim out.
