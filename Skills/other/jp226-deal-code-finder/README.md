# JP226 Deal Code Finder

Created by JP226Prints.

Tell Claude where you want to buy and what discount you are after. This skill searches OzBargain and other Australian deal and coupon sites, checks what it finds, and gives you a short ranked list of codes and other ways to save, each with its source and date.

## What it does

- Searches OzBargain and similar Australian coupon sites for the merchant you name.
- Reads the merchant's own offers page for specials, book direct deals and sign-up offers.
- Looks for membership and concession rates, cashback and discounted gift cards.
- Marks each result High, Medium or Low confidence, based on how recent it is and what people say about it.
- Tells you honestly when nothing good turns up.

It never invents a code, never buys or books for you, and never signs you up to anything.

## Installation

1. Download the latest `.skill` file from the Releases page of the repository.
2. In Claude, open Settings, then Skills, and upload the file.
3. Make sure web search is switched on.

## Usage examples

> Find me a promo code for G'day Parks. I want about 15% off a 5 night caravan site in January.

> Any discount for Discovery Parks or Big4 for a weekend in November? I'm an NRMA member.

> Check OzBargain for Repco. I'm after 20% off.

Each answer opens with how well the best result matches what you asked for, then a table with the code or how to get it, what it gives, the conditions, when it was last confirmed and the source link.

## Good to know

- A code can only be proven at the merchant's checkout. Treat every code as a lead until it works.
- It reads public pages only. Codes in apps, behind logins or sent by email are out of reach.
- It is built for Australian merchants and dollars.
- Deal sites come and go. The list in `references/sources.md` is a starting point you can edit.
